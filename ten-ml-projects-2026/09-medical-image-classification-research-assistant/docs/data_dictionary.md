# Data dictionary — Medical Image Classification Research Assistant

**Provenance:** Synthetic generator defined in `engine.py`, except MLOps using the bundled Iris dataset.

**Mode:** `medical`. Inspect the `features` field in generated `artifacts/metrics.json` for exact numeric input order. Search uses original toy tri-lingual passages; recommender uses integer user/item identifiers; vision uses artificial 32×32 grayscale arrays.

**Labels:** Only simulator-created labels, not independently verified ground truth. No PII collected.
